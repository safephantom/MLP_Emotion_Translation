# KEMDy19 기반 멀티모달 감정 인식 (모델링 백본)

**한국어 버전** | 🔗 **[English Version](./README.en.md)**

---

이 디렉토리는 본 프로젝트의 전처리 엔진 역할을 하는 **감정 인식 백본 모델링** 파트입니다. KEMDy19 데이터셋을 활용하여 이산 감정 범주를 분류하는 동시에, 차원적 정서 지표인 **Valence(긍정/부정) 및 Arousal(활성도)**을 함께 예측하는 멀티모달 신경망을 학습합니다.

핵심 설계 요소는 한국어 구어체의 감정 표현에서 중요한 구조적 힌트가 되는 **음향 자질**과 **문장 종결어미(EF)** 확률 분포 정보를 결합하여 모델링에 주입하는 것입니다.

---

## 1. 방법론 및 모델링 전략

### 1.1. Soft Labeling (라벨 분포 학습)
하나의 원핫 인코딩(One-hot Encoding) 정답만을 강제하는 기존 분류기와 달리, 본 모델은 **Soft Labeling** 기법을 도입했습니다. KEMDy19 데이터셋의 각 발화에 대해 10명의 인간 평가자가 투표한 감정 분포(예: 분노 60%, 슬픔 40%)를 모델이 그대로 모사하도록 학습합니다. 이를 통해 인간이 느끼는 복합적이고 미묘한 감정선 표현을 학습할 수 있습니다.

### 1.2. 다중 작업 학습 (Multi-task Learning)
화자의 전반적인 정서 상태를 다각도로 파악하기 위해, 모델은 아래의 세 가지 작업을 동시에 수행하도록 설계되었습니다.
1. **이산 감정 분류**: 7개 감정 범주(분노, 슬픔, 기쁨, 공포, 혐오, 놀람, 중립)에 대한 확률 분포 예측.
2. **Valence(긍정/부정) 회귀**: 화자의 정서 상태가 긍정적인지 부정적인지 측정.
3. **Arousal(활성도) 회귀**: 화자의 정서적 각성 및 흥분 강도 측정.

최종 손실 함수는 감정 분류의 크로스 엔트로피 손실과 Valence/Arousal의 평균 제곱 오차(MSE) 손실을 결합하여 구성됩니다.
$$
\mathcal{L}_{total} = \alpha \cdot \mathcal{L}_{Emotion} + \beta \cdot \mathcal{L}_{Valence} + \gamma \cdot \mathcal{L}_{Arousal}
$$

### 1.3. Optuna를 통한 하이퍼파라미터 최적화
모델 성능 극대화를 위해 Optuna 프레임워크를 도입하여 50회 이상의 대규모 탐색 작업을 수행하였으며, 최적의 네트워크 하이퍼파라미터 조합을 아래와 같이 도출했습니다.
* **학습률(Learning Rate)**: 0.0039
* **배치 크기(Batch Size)**: 32
* **LSTM 은닉층 차원(Hidden Dimension)**: 128
* **드롭아웃 비율(Dropout Rate)**: 0.41

## 2. 가설 검증: 절제 연구
"한국어는 끝말(종결어미)을 들어야 진짜 감정을 파악할 수 있다"는 핵심 가설을 입증하기 위해 **절제 연구(Ablation Study)**를 수행했습니다.
* **실험군(Proposed)**: 음향 자질 + 종결어미(EF) 감정 매핑 분포 정보 결합.
* **대조군(Ablated)**: 종결어미 힌트를 균등 분포($1/7$)로 강제 마스킹하여 음향 정보만 노출.

### 실험 결과

| 모델 설정 | 학습 모달리티 | 최저 검증 손실 | Hard Acc (정확도) | Soft Acc (분포 유사도) | V Loss (Valence MSE) | A Loss (Arousal MSE) |
| :--- | :--- | :---: | :---: | :---: | :---: | :---: |
| **멀티모달 (실험군)** | **음향 + 종결어미(EF)** | **1.4470** | **59.17%** | **54.44%** | **0.0501** | **0.0168** |
| **음향 단독 (대조군)** | 음향 단독 (EF 마스킹) | 1.6808 | 44.28% | 46.14% | 0.0660 | 0.0203 |

#### 결과 분석
* **분류 정확도 하락**: 종결어미 정보를 제외하자 정확도(Hard Accuracy)가 약 60%에서 45%대로 **약 15%p 가량 하락**했습니다. 이는 음성 톤만으로는 한국어 구어체의 감정을 분별하기 어려우며, 종결어미 정보가 감정 판단에 핵심 힌트가 됨을 실증합니다.
* **Valence 예측력 저하**: Valence 손실이 약 32% 증가하여, 화자의 긍정/부정 태도를 파악하는 데 종결어미의 어조 구조가 결정적 기여를 하고 있음을 보여줍니다.

## 3. 파일 구조 및 설명

* **`02_train_multimodal.py`**: 음향 자질과 종결어미(EF) 가중치를 결합한 멀티모달 네트워크 훈련 스크립트.
* **`03_train_audio_only.py`**: 종결어미 자질을 마스킹하여 음향 단독 성능을 검증하는 절제 연구용 훈련 스크립트.
* **`01_optimize_hyperparams.py`**: Optuna 탐색을 사용하여 하이퍼파라미터 최적화 조합을 도출하는 스크립트.
* **`final_report_modeling.md`**: 가설 검증부터 학습 기법, 하이퍼파라미터 최적화 모델링 과정을 담은 국문 종합 보고서.
* **`merged_dataset_soft_fixed.csv`**: 10명의 평가자 감정 투표 분포(Soft Label)가 반영된 데이터셋.
* **`dynamic_ef_weights_fixed.csv`**: 한국어 종결어미별 감정 카테고리 매핑 확률 테이블.
* **`kemdy19_multimodal_lstm.pth`**: 검증 손실이 가장 낮은 최적 멀티모달 모델 가중치 파일.
* **`kemdy19_audio_only.pth`**: 음향 단독 baseline 모델 가중치 파일.

## 4. 실행 가이드 및 재현

새로운 환경에서 모델을 재학습하려면 다음 단계를 진행합니다.
1. 음향 추출 피처 zip 파일을 다운로드하여 `cached_features/` 폴더에 압축을 해제합니다.
2. 멀티모달 훈련 스크립트를 실행합니다.
   ```bash
   python modeling/02_train_multimodal.py
   ```
3. 새로운 하이퍼파라미터 최적 조합을 탐색하려면 다음을 실행합니다.
   ```bash
   python modeling/01_optimize_hyperparams.py
   ```
